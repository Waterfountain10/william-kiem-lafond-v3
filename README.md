# William Kiem-Lafond — personal website

Astro foundation for a personal technical notebook. Visual implementation is intentionally pending the owner's Figma mockup.

## Commands

```sh
npm install
npm run dev
npm run check
npm run build
```

## Structure

- `src/content/notes/` — Markdown and MDX writing
- `src/content/projects/` — verified project entries
- `src/content.config.ts` — content schemas
- `src/styles/tokens.css` — editable visual candidates and design tokens
- `docs/references/` — supplied visual references

## Current design candidates

The token file records, but does not yet choose between, Georgia, Instrument Serif, and Libre Baskerville for display type; Arial, Be Vietnam Pro, and DM Sans for body type. Initial palette candidates are paper `#f4f1e8`, dark gray ink, and green `#aab500`.

No biographical claims, project records, font files, or final composition have been added pending verified content and the Figma design.
